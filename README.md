## **Titanic Survival Prediction using Naive Bayes Algorithm**

### **Overview**

This project focuses on predicting the survival of passengers aboard the Titanic using the **Naive Bayes classification algorithm**. By analyzing passenger information such as age, gender, and socio-economic class, the model learns patterns that help estimate the probability of survival. The project demonstrates the complete machine learning pipeline including data preprocessing, feature selection, model training, and evaluation.

---

### **Features**

* Data cleaning and preprocessing
* Categorical encoding and numerical feature handling
* Gaussian Naive Bayes classification
* Model training and testing
* Performance evaluation using accuracy and classification metrics

---

### **Technologies Used**

* Python
* NumPy
* Pandas
* Scikit-learn
* Matplotlib
* Seaborn

---

### **Dataset**

The Titanic dataset contains passenger details such as:

* Passenger class
* Gender
* Age
* Fare
* Survival status

---

### **Feature Selection**

The following features are used for prediction:

* **Pclass** – Socio-economic class (1 = Upper, 2 = Middle, 3 = Lower)
* **Sex** – Gender of the passenger
* **Age** – Age of the passenger
* **Fare** – Ticket fare

---

### **Algorithm**

The project uses **Gaussian Naive Bayes**, a probabilistic machine learning algorithm based on Bayes’ Theorem. It assumes independence between features and is effective for classification problems with continuous data.

---

### **Workflow**

1. Data Preprocessing
2. Feature Encoding and Scaling
3. Model Training
4. Model Testing
5. Model Evaluation

---

### **Model Evaluation**

The model performance is evaluated using:

* Accuracy
* Classification Report (Precision, Recall, F1-score)

---

### **Conclusion**

This project provides a clear and beginner-friendly implementation of Naive Bayes for classification and serves as a strong foundation for understanding probabilistic machine learning models.
